# TreasuryFlows website

Static site (plain HTML/CSS, no build step) for TreasuryFlows, hosted on GitHub Pages.

## Structure

- `index.html` — Home
- `services.html` — Services
- `about.html` — About
- `contact.html` — Contact
- `styles.css` — shared stylesheet
- `assets/` — images

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static file server.

## Deploy

Pushed to GitHub Pages from this repo (see repo Settings → Pages).
